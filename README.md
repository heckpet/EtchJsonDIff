# EtchJsonDIff

I asked Claude to generate this tool as I faced the issue, that I usede the Etch Mega Menu Pro ( https://designwithcracka.gumroad.com/l/Etch-Mega-Menu-Pro-standard ) and wanted to be able to identify changes done by the developer and implement them on my customers website without breaking something.
Simply upload the two JSON files which should be compared and check files for any changes. Afterwards you can decide, which changes you want to apply on your website. I have not added the capability to automatically apply such chnages, as I want to do it by my owen in order to have full control, what should be changed. But feel free to feed the files to the LLM of your chaise and ask it to anhance it.
